# FormCraft 低代码表单搭建器

基于 Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router 与 VueUse 构建。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

端到端逻辑验证（发布冻结 / 版本锚定 / 答案迁移 / 写入容错，共 54 项断言）：

```bash
pnpm verify
```

## 已实现

- 左侧组件库拖入画布，支持输入框、选择器、日期、表格、分组、自定义容器。
- 节点递归渲染与拖拽排序，分组和容器支持嵌套落点。
- 右侧属性面板配置标题、字段名、占位提示、表格列、校验规则和条件显隐。
- 画布 Schema 可导出、导入 JSON（旧版 fieldId 联动自动归一化为字段路径）。
- 基于快照的撤销重做、删除、复制节点。

### 草稿 / 发布版本 / 填单会话三层模型

- **设计稿（草稿）**：设计器的编辑只落在草稿，自动原子保存到本地，与发布版本互不影响。
- **发布版本（冻结）**：点击「发布版本」会把当前草稿的字段结构、校验规则与联动条件整体冻结为不可变版本（v1、v2…）。发布后继续修改只停留在新草稿，不改变任何已发布版本。
- **填单会话（锚定版本）**：每个会话记录开始时的版本号，恢复与显隐、必填、长度、正则、范围校验都按该冻结版本执行；发布新版本不会带动已开始的会话。
- **答案迁移**：会话落后于新版本时可手动迁移。按字段路径（含分组/容器嵌套段）逐字段比对：
  - 路径与结构对得上（表格还要求列集合一致）：答案直接补入；
  - 字段被删/改名：旧值列为待处理，可选择补入同类型的新字段，或两边都保留；
  - 同路径类型/表格结构变化：新值取默认、旧值保留，同样列待处理；
  - 保留的旧值长期挂在会话上，不随提交丢失。
- **迁移可重试**：迁移开始时保存旧版本答案快照；规划或写入失败会话原样保留，随时可重试或放弃并回到开始时版本。全部待处理项解决后才正式切换版本，未完成迁移不能提交。
- **字段标识即唯一键**：标识改名走合法性与唯一性校验；一旦标识变化导致联动目标路径消失，设计器与预览中的相关联动条件立即失效（字段隐藏并标红），重新选择条件字段后恢复。
- **原子持久化**：草稿、发布版本、会话分别存独立文档，写入时先写临时文档并回读校验，再切换主文档；写入中断不会破坏上一版数据，逐字段保存也不会丢失已录答案。

## 页面

- `设计器`：编辑草稿并发布冻结版本，工具栏显示当前发布版本与「草稿有未发布修改」标记。
- `草稿预览`：实时预览当前草稿，顶部集中提示失效联动。
- `填单会话`：会话列表与按锚定版本渲染的填写页，支持新建会话、版本迁移、待处理冲突解决与提交。
