# FormCraft 低代码表单搭建器

基于 Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router 与 VueUse 构建。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 已实现

- 左侧组件库拖入画布，支持输入框、选择器、日期、表格、分组、自定义容器。
- 节点递归渲染与拖拽排序，分组和容器支持嵌套落点。
- 右侧属性面板配置标题、字段名、占位提示、表格列、校验规则和条件显隐。
- 画布 Schema 可导出、导入 JSON。
- 基于快照的撤销重做、删除、复制节点。
- 实时预览页面可填写数据并展示条件显隐、必填、长度、正则和范围校验结果。
- 示例数据与设计状态保存在 Pinia；已完成的 Schema 会写入 localStorage。

## 发布版本与填单会话

- **发布冻结**：点击「发布版本」会把当前草稿的字段结构、校验规则和联动条件深拷贝为不可变快照；发布后继续修改只留在新草稿，不影响已发布版本。
- **按版本填写**：在「填写会话」中选择任一发布版本开始填写，会话绑定该版本并按其恢复与判断；答案按字段路径（如 `reasonSection/detail`）写直通落盘，写入失败时答案仍保留在内存中不丢失，可重试。
- **字段标识改名失效**：在设计器中修改字段标识（`name`）后，引用它的联动条件立即标记为失效，实时预览按「始终显示」重算并提示；属性面板与画布节点会标出失效条件。
- **版本迁移**：发布新版本后，未提交会话可一键迁移。按字段路径匹配：对得上且类型一致的直接补入；对不上的两边值都保留并列为待处理，可逐条采用旧值 / 新值 / 保留待处理。
- **失败可重试**：迁移先纯计算后提交，失败时原会话保留并标记 `migration_failed`，可重试迁移；迁移成功后会话切换到新版本并记录迁移时间。
